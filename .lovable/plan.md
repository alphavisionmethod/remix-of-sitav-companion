# Plan — iOS Native Runtime, Truly Real

## North star
A bootable, signed iOS app — generated entirely in CI on a `macos-14` runner (zero Mac needed by you), with every advanced capability (push, secure storage, biometrics, deep links, background, crash reporting) wired at the Capacitor/JS layer **before** the native shell is generated, so the first build is production-grade.

## Honest constraint (won't change)
| Step | Where it runs |
|---|---|
| Pre-stage templates, plugins, configs, CI | ✅ Lovable sandbox (now) |
| `npx cap add ios` (creates `ios/` folder, binary `.xcodeproj`) | ❌ macOS required → ✅ GitHub `macos-14` runner |
| `pod install` (creates `ios/App/App.xcworkspace`) | ❌ macOS required → ✅ same runner |
| Sign + archive + upload to TestFlight | ❌ macOS required → ✅ same runner |

I will **not** commit a fake `App.xcworkspace`. Real one comes from the macOS CI runner.

## What ships this turn

### 1. Capacitor plugin layer (advanced capabilities)
Install via `add_dependency`:
- `@capacitor/push-notifications` — APNs (transport stays deferred per project policy; plugin present, edge wiring inert until Apple Dev Program funded)
- `@capacitor/preferences` — keychain-backed storage (already present, verify)
- `@capacitor-community/biometric-auth` — Face ID / Touch ID
- `@capacitor/app` — deep links + lifecycle (present, verify)
- `@capacitor/network`, `@capacitor/device` — present, verify
- `@capacitor/background-runner` — background sync hooks
- `@sentry/capacitor` + `@sentry/react` — native + JS crash reporting

### 2. Native bridge wiring → `src/lib/mobile-platform/native/`
- `push.ts` — register device, send token to `device-tokens` table, gracefully no-op when APNs deferred (uses existing pattern in `src/lib/mobile-platform/permissions.ts`)
- `biometrics.ts` — gate approvals/payments via existing trust-tier system
- `secure-storage.ts` — keychain wrapper, used by auth token persistence
- `deeplinks.ts` — listener that dispatches to React Router; URL scheme `sita://`, Universal Links `applinks:e245cf40-61cc-4143-bfa4-f97382e8d62d.lovable.app`
- `background.ts` — register `app-refresh` task hitting `/health` edge function
- `crash-reporter.ts` — Sentry init with environment + release tag

### 3. Pre-staged native templates → `ios-templates/App/App/`
Files Capacitor's generator merges with on first `cap add ios`:
- `Info.plist` — full plist with every permission usage string sourced from `permissions.ts` (camera, mic, Face ID, photos, location, contacts, push)
- `App.entitlements` — keychain access groups, associated domains, push environment (commented `<!-- aps-environment -->` block, one-line uncomment when APNs funded), background modes
- `PrivacyInfo.xcprivacy` — Apple privacy manifest (UserDefaults, file timestamp, boot time, no tracking)
- `Assets.xcassets/AppIcon.appiconset/` — 1024×1024 master + Contents.json (14 size slots; sizes derived in CI via `sips`)
- `LaunchScreen.storyboard` — branded `#0b0f17` launch
- `Podfile` — pinned Capacitor pods, `use_frameworks! :linkage => :static`

### 4. Cloud bootstrap → `.github/workflows/ios-bootstrap.yml`
**This is the keystone.** `macos-14` runner:
1. Checkout, setup-node 20, `npm ci`
2. `npm run build`
3. `npx cap add ios` (generates `ios/`)
4. Overlay `ios-templates/App/App/*` onto generated `ios/App/App/*` (Info.plist, entitlements, privacy, icons, storyboard)
5. Generate icon sizes from 1024 master via `sips`
6. `cd ios/App && pod install` (creates real `App.xcworkspace`)
7. `npx cap sync ios`
8. Smoke build for iPhone 15 simulator: `xcodebuild -workspace ios/App/App.xcworkspace -scheme App -sdk iphonesimulator -configuration Debug build`
9. Two output modes:
   - `workflow_dispatch` input `commit_back: true` → commits `ios/` + opens PR
   - default → uploads `ios/` tree as artifact

After PR merges (or artifact extracted), the existing `.github/workflows/release-ios.yml` can sign + ship via `build-ios.sh`.

### 5. Harden `scripts/release/ios/build-ios.sh`

### 7. Operator runbook → `docs/ios/IOS_NATIVE_RUNTIME.md`
