# Trust Copy & Premium Feel Audit

All upgraded empty-state copy follows the SITA OS trust copy principles:

- **Precise** — names the actual condition (e.g. "No webhook subscriptions")
- **Truthful** — explains why the state is empty (opt-in not granted, scanner not run, no events emitted)
- **Operator next-step** — tells the admin what action would change the state
- **No magical phrasing** — no "AI magic", no "soon", no marketing language
- **No forbidden phrases** — TODO, FIXME, lorem, alert(), console.log are gated by `check-trust-copy-quality.ts`
