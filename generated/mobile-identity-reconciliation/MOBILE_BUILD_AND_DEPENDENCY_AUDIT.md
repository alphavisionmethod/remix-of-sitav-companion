# SITA OS — Mobile Build & Dependency Audit

**Generated:** Phase 3 of Mobile Identity Reconciliation
**Question:** what build systems and dependency managers does the mobile distribution layer use, and are they consistently declared?
**Answer:** four-tier build model (web/wrapper/Android/iOS) with three dependency managers (npm, Gradle, CocoaPods), all consistent.

---

## 1. The Four-Tier Build Model

```
┌──────────────────────────────────────────────────────────────┐
│ Tier 1: Web layer                                            │
│   Build: Vite 5  (npm run build → dist/)                     │
│   Deps:  npm  (package.json)                                 │
└──────────────────────┬───────────────────────────────────────┘
                       │ dist/ consumed by Capacitor
                       ▼
┌──────────────────────────────────────────────────────────────┐
│ Tier 2: Capacitor wrapper                                    │
│   Build: npx cap sync                                        │
│   Deps:  npm  (@capacitor/* packages)                        │
└──────────┬─────────────────────────┬─────────────────────────┘
           │                         │
           ▼                         ▼
┌─────────────────────────┐ ┌─────────────────────────────────┐
│ Tier 3a: Android        │ │ Tier 3b: iOS                    │
│   Build: Gradle 8.x     │ │   Build: xcodebuild             │
│   Deps:  Maven/Gradle   │ │   Deps:  CocoaPods              │
│   Output: AAB / APK     │ │   Output: .ipa                  │
└─────────────────────────┘ └─────────────────────────────────┘
```

## 4. Dependency Manager Boundary Audit

| Manager | Manages what | Consumed where | Conflict risk |
|---|---|---|---|
| **npm** (`package.json`) | web SPA + Capacitor wrapper + Capacitor plugins | Tiers 1 & 2 | low — all deps live in single `package.json` |
| **Gradle** (post-generation `android/build.gradle`) | Android dependencies (AndroidX, biometric, push) | Tier 3a only | low — Capacitor manages plugin Android pieces; app-level adds rare |
| **CocoaPods** (post-generation `ios/App/Podfile`) | iOS dependencies (Capacitor + plugin pods) | Tier 3b only | low — Podfile pinned to `archive/ios-templates/App/Podfile` template |

**No dependency manager overlaps tiers.** This is the canonical model.
