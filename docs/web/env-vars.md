# Web Deployment — Environment Variables

This is the **single source of truth** for environment variables required to run
the SITA OS web SPA in production. It supersedes the aspirational monorepo
schema in `docs/refactor/env-schemas.md`.

All variables prefixed with `VITE_` are baked into the client bundle at build
time and are therefore **public**. Do not put secrets here.

## Required (auto-provisioned by Lovable Cloud)

These three are written to `.env` automatically and must not be edited by hand.

| Variable | Purpose | Example |
|---|---|---|
| `VITE_SUPABASE_URL` | Backend project URL | `https://fctupowhcljejygjfpty.supabase.co` |
| `VITE_SUPABASE_PUBLISHABLE_KEY` | Anon key for client-side Supabase calls | `eyJhbGci...` |
| `VITE_SUPABASE_PROJECT_ID` | Project ref used by typegen / debug surfaces | `fctupowhcljejygjfpty` |

## Optional (set before production deploy)

| Variable | Purpose | Default behavior if unset |
|---|---|---|
| `VITE_PUBLIC_HOST` | Canonical public URL for SEO / OG / sitemap rewrite | Falls back to placeholder `https://app.sita.os` |
| `VITE_VAPID_PUBLIC_KEY` | Web Push public key (VAPID) for browser push subscriptions | Web push subscriptions silently disabled |

## Build-only (Node, not Vite)

| Variable | Purpose |
|---|---|
| `WEB_PUBLIC_HOST` | Used by `scripts/release/web/rewrite-public-host.ts` to swap placeholder domain in `sitemap.xml`, `robots.txt`, `index.html` canonical, and `manifest.webmanifest`. Run once per deploy. |

## Verification

After running `npm run build`, the following should be true:

1. `dist/index.html` contains the expected CSP and canonical URL.
2. `dist/sitemap.xml` and `dist/robots.txt` reflect `WEB_PUBLIC_HOST`.
3. `dist/sw.js` and `dist/sw-push.js` reference `/icons/icon-192.png` (not `/pwa-*.png`).
4. `dist/health.json` is generated by the Vite healthcheck plugin.

## Server-side (edge functions, not Vite)

These live in Supabase Edge Function secrets, **never** in the client bundle:

- `LOVABLE_API_KEY` — for AI Gateway invocations from edge functions
- `VAPID_PRIVATE_KEY`, `VAPID_SUBJECT` — for sending web pushes from edge functions
- `STRIPE_SECRET_KEY` — when Stripe is enabled
- All other private API keys
