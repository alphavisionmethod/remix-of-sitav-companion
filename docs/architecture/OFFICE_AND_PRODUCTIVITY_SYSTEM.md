# SITA OS — Office & Productivity System

## Purpose

Lightweight document creation within the OS shell. Not a full office suite replacement, but sufficient for common business/family needs.

## Workspaces

| Workspace | Purpose |
|-----------|---------|
| Docs | Text documents, notes, memos |
| Sheets | Spreadsheets, budgets, trackers |
| Slides | Presentations, boardroom decks |

## Integration Points

- **Boardroom** — Auto-generate presentation from boardroom packet
- **Business** — Proposal and quote templates
- **Finance** — Budget spreadsheets, expense trackers
- **Concierge** — Checklists, itineraries, planning docs
- **Files** — All docs stored in files system

## Template System

Templates linked to packs:
- Business proposal template
- Invoice template
- Family budget template
- Travel itinerary template
- Boardroom deck template
- Meeting notes template

## Collaboration

Future: Real-time collaboration within household/org.
Current: Single-user editing with version history.
