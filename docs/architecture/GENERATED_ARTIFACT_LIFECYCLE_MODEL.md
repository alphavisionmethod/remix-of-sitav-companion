# SITA OS — Generated Artifact Lifecycle Model

> Wave B (Constitution Rule §B.1, **BLOCKING**). Every file under `generated/**` carries a lifecycle class, a freshness TTL, an owning generation script, and a publishability disposition. Drift is detected by `check-generated-artifact-governance.ts`.

## Authority

- **Constitutional rule:** Repository Constitution §B.1 — Generated Artifact Lifecycle Law.
- **Canonical manifest:** `generated/manifests/generated-artifact-governance-map.json`.
- **Canonical policy:** `generated/manifests/generated-artifact-freshness-policy.json`.
- **Validator:** `scripts/architecture/checks/check-generated-artifact-governance.ts` (BLOCK).
- **Generator:** `scripts/architecture/generate/generate-artifact-governance-map.ts`.
- **Baseline (orphans):** `generated/baselines/orphan-artifact-baseline.json` (917 pre-Wave-B entries pinned; ratchet-only).

## The four lifecycle classes

| Class | Definition | TTL | CI on stale | CI on missing | Publish to `public/generated/**` |
|---|---|---|---|---|---|
| `active-blocking` | Read by a STRICT/BLOCK validator (classification = `block` in `src/lib/ci/validator-gate-map.ts`) | 7 days | **fail** | **fail** | only if explicitly allowlisted in `public-mirror-policy.ts` |
| `active-informational` | Read by a WARN / advisory validator or by a dashboard | 30 days | warn | warn | yes, if matched by mirror policy |
| `reference` | Engineer/audit lookup, not gated by any check | 180 days | label-only | none | yes, if matched by mirror policy |
| `historical-archived` | Frozen wave/audit snapshot or baseline pin | n/a | none | none | yes (immutable) |

## Classification rules (deterministic)

The generator classifies every file in `generated/**` by:

1. If path matches `generated/audits/wave-*`, contains `historical`, or ends in `-baseline.json` → `historical-archived`.
2. Else if any check in `scripts/architecture/checks/` whose validator basename appears in `VALIDATOR_GATE_OVERRIDES` with `classification: "block"` references the path → `active-blocking`.
3. Else if any check in `scripts/architecture/checks/` references the path → `active-informational`.
4. Else → `reference`.

## Owning script rule

Every artifact must be produced by exactly one script under `scripts/**`. The generator infers ownership by scanning for `writeFileSync` / `writeJSON` / `emitGateReport` calls that include the artifact path.

- `active-blocking` and `active-informational` artifacts **must** declare an owning script (or be on the orphan baseline).
- `reference` artifacts **should** declare one; orphans warn-only.
- `historical-archived` artifacts are exempt (snapshots).

## Publishability rule

An artifact is permitted to appear in `public/generated/**` **iff** it matches an entry in `MIRROR_RULES` (`scripts/architecture/lib/public-mirror-policy.ts`) **and** is not classified `active-blocking` (unless explicitly allowlisted). Mirror integrity is enforced by `check-public-artifact-mirror.ts` (already BLOCK).

## Archival / deletion policy

- `historical-archived` files are **immutable**: never overwritten, never deleted by the freshness sweep. They migrate via `scripts/clean-generated.sh` only after explicit ADR.
- `reference` files older than 180 days are eligible for archive but not auto-pruned.
- `active-*` files that go stale must be regenerated by their owning script before release.

## Amendment process

New lifecycle classes or TTL changes require:
1. ADR under `docs/architecture/`.
2. Update of this document AND `generated/manifests/generated-artifact-freshness-policy.json`.
3. Update of the generator script.
4. Re-seal via `scripts/architecture/wave-10-emit-attestation.ts`.
