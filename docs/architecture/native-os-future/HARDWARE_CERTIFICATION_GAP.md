# Hardware Certification & OEM Program — GAP

**Classification:** Future / native-substrate. **Not implemented.**

## What this would require

OEM certification program, reference hardware specs, lab compliance (FCC/CE/etc.), preinstall agreements, OEM key custody, recovery image distribution, and a long-tail driver/QA pipeline.

## What SITA OS actually does today

- Runs on whatever hardware the host OS supports.
- No OEM partnerships, no certified hardware list.
- Appliance tier ships as a VMware/qemu image — distro-certified hardware compatibility, not SITA-certified.

## Honesty boundary

- ❌ No "certified hardware" language.
- ✅ "SITA OS runs on any modern device that supports a recent browser, Electron host, or Linux VM" is accurate.
