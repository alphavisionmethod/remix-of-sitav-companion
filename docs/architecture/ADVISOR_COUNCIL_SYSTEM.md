# SITA OS — Advisor Council System

## Core Truth

The Main Guide is the calm conductor of the OS, not the source of truth.
Advisors are a council of domain specialists, not chatbots.
Proof, receipts, and action history remain primary.

## Main Guide Identity

- Visual: Calm gradient icon, premium typography, no avatar/face
- Role: Orchestrator, not answerer. Routes to specialists.
- Modes: Daily Pulse, Business, Money, Concierge, Boardroom, Executive

## Advisor Council

| Advisor | Domain | Specialty |
|---------|--------|-----------|
| Business Advisor | business-os | CRM, pipeline, revenue, client health |
| Money Advisor | finance-os | Cash flow, bills, reserves, investments |
| Concierge Advisor | concierge-os | Household, calendar, travel, errands |
| Strategy Advisor | cross-domain | Opportunities, risks, boardroom synthesis |

## Trust Pipeline (10 States)

```
proposed → drafted → simulated → approval-requested → approved
→ executing → completed → verified → [failed | rolled-back | escalated]
```

## Council Views

1. **Overview** — All advisors in council grid with health, confidence, recent actions
2. **Single Advisor** — Deep workspace with tracks, memory, approvals, proof
3. **Compare** — Multi-advisor synthesis with visible disagreements
4. **Simulations** — Scenario comparison studio
5. **Approvals** — Approval-ready action cards
6. **Memory** — Transparency cards showing what each advisor knows and why
7. **Proof** — Audit history with receipt hashes

## Disagreement Protocol

When advisors disagree:
- Both positions shown with confidence scores
- Reasoning chains visible
- User decides (not system)
- Decision recorded as proof

## Confidence Ladder

| Score | Display |
|-------|---------|
| 0.9+ | High confidence, green |
| 0.7-0.9 | Moderate, amber |
| 0.5-0.7 | Low, orange with caveats |
| <0.5 | Refused or heavily caveated |

## Memory Transparency

Each advisor shows:
- What data sources it reads
- How fresh each source is
- What it remembers about the user
- What preferences it has learned
- What it does NOT know (gaps)

## Approval-Ready Actions

Cards showing:
- What the advisor wants to do
- Why (reasoning chain)
- What it affects (workflows, data, money)
- Confidence score
- Required approval level
- Approve / Reject / Simulate first
