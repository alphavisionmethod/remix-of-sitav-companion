# SITA OS — Observability & Diagnostics

## Native log surfaces

| Source | Path / journal unit |
|---|---|
| Boot | `journalctl -b` |
| First boot | `sita-firstboot.service` + `/var/log/sita-firstboot.log` |
| Runtime shell | `sita-runtime.service` |
| Updater | `sita-updated.service` |
| Recovery | `sita-recovery.service` |
| Verity events | `dmesg` (kernel) |
| Crash dumps (Electron) | `/var/lib/sita/crashes/*.dmp` → `crash-report-ingest` edge fn |

## Support bundle

Generated by `os/scripts/generate-support-bundle.sh`. Includes:

- host metadata (kernel, version, channel, slot)
- 2000-line journal of current + previous boot
- per-service status + last 500 log lines
- `/etc/sita/`, rollback receipts, boot entries
- attestation file
- `veritysetup status sita_root`

Secrets are redacted (JWTs, Stripe keys, license keys, password=…).
Output: `/var/lib/sita/support/sita-support-<host>-<ts>.tar.zst`.

## Phone-home (optional, opt-in at first boot)

If enabled, the device sends:

- channel + version + slot
- last rollback timestamp (no payload)
- crash counts (no stack traces)

…to `supabase/functions/crash-report-ingest`. Disabled by default.
