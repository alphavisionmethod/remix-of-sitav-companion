# SITA OS — Owner Mode Guide

## Purpose

Owner Mode gives the account owner full visibility and control over the AI operating system, including areas normally handled automatically.

## Owner-Only Capabilities

| Capability | Description |
|-----------|-------------|
| Safe Mode | Emergency automation pause |
| Advisor Autonomy | Upgrade/downgrade advisor trust levels |
| Agent Control | Pause/resume internal agents |
| Policy Override | Temporarily modify policy boundaries |
| Cost Limits | Set daily/weekly token budgets |
| Connector Control | Enable/disable/reconnect integrations |
| Pack Management | Install/uninstall/pause packs |
| Proof Review | Full audit trail access |
| Diagnostic Export | Generate support-safe diagnostic bundles |

## Access

Owner Mode is accessible via:
- Mission Control (primary)
- Settings → Owner Controls
- Command Palette → "Owner Mode"

## Proof Trail

Every owner action generates proof:
- What was changed
- Previous state
- New state
- Timestamp
- Reason (if provided)

## Multi-Owner

For household/org accounts:
- Multiple owners possible
- Dual-approval for critical actions
- Owner audit trail per person
