# iOS Native Templates — SITA OS

These files are **pre-staged** to be overlaid onto the Capacitor-generated `ios/` tree by:

- `.github/workflows/ios-bootstrap.yml` (cloud, recommended — no Mac required)
- `scripts/ios/bootstrap.sh` (local Mac path, optional)

Both flows perform:

```
npx cap add ios          # generates ios/ (binary .xcodeproj — Mac-only)
rsync -a ios-templates/App/App/  ios/App/App/   # overlay our hardened files
cd ios/App && pod install                       # generates App.xcworkspace
npx cap sync ios
```

## Why pre-staged?

The Lovable sandbox is Linux. `.xcodeproj`/`.xcworkspace` are macOS-specific binary
plists generated by Capacitor + CocoaPods. Faking them = broken first build.

By pre-staging only the **plain-text overrides** (Info.plist, entitlements, privacy
manifest, launch storyboard, Podfile, app icons), we get a production-grade native
project the moment the macOS bootstrap runs — without committing any Apple-toolchain
binary artifacts here.

## Layout

```
ios-templates/
└── App/
    └── App/
        ├── Info.plist                 # Permissions usage strings
        ├── App.entitlements           # Keychain, associated domains, push (deferred)
        ├── PrivacyInfo.xcprivacy      # Apple privacy manifest
        ├── LaunchScreen.storyboard    # #0b0f17 branded launch
        ├── Assets.xcassets/
        │   └── AppIcon.appiconset/
        │       ├── AppIcon-1024.png   # Master, all sizes derived in CI via `sips`
        │       └── Contents.json
        └── Podfile                    # Pinned Capacitor pods, static linkage
```

## APNs status

The `aps-environment` entitlement key is **commented out** until the Apple Developer
Program membership is funded. One-line uncomment when ready — no other code changes
required (push plugin and edge wiring already present, gracefully no-op meanwhile).
